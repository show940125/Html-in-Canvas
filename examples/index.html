HTML IN CANVAS / PRACTICAL EXAMPLES

每個像素背後，都有可以操作的 HTML。

這些範例使用與 Canvas Clipper 相同的能力偵測、互動幾何及紋理上傳程式。

01 · 互動 DOM

真正的文字欄、中文輸入、按鈕及選取。觀察 DOM 如何對齊畫布。

02 · 合成與圖片輸出

HTML、SVG 關係線與表單一起合成，再下載完整 PNG。

03 · WebGL 翻頁

HTML 紋理映射至可彎曲頁面，翻動時暫停命中，停穩後恢復輸入。

先執行 repo 建置產生 runtime.js，再以 HTTP 提供此目錄。Chrome 156 開啟 canvas-draw-element；程式會顯示實際能力。
