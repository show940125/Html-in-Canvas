Canvas Clipper

開源 HTML-in-Canvas 互動式閱讀桌。v0.2 開發基線；v0.3 開發中。

載入

  1. 建置專案或解壓發布的 ZIP。
  2. 在 Chrome 擴充功能頁開啟開發人員模式。
  3. 按「載入未封裝項目」，選擇建置後的 Canvas Clipper/dist。

資料與遷移

資料存於 Chrome 設定檔內。先從原安裝匯出全部專案，再於新安裝「備份 / 匯入」匯入。核對卡片及筆記後保存全部專案 ZIP。舊版匯出橋接頁為原插件來源下的 migration.html，可由原插件 ID 開啟。

使用

選取網頁文字後按右鍵加入，或由工具列匯入文章。閱讀全文、並排比較、主題框、標籤及關係線協助整理材料。文件檢視輸出可搜尋 PDF；ZIP 保存完整本機資料。

相容性

Chrome 156 開啟 canvas-draw-element 後測試原生模式。依實際能力切換 HTML 相容模式；實驗 API 的版本差異另有能力探測。
