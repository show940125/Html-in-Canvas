第一次使用，先試範例專案

在空白閱讀桌按「試用範例專案」。它會建立獨立的合成示例，保留你的其他專案。

01抓住文章

拖曳卡片頂端，移向主題框。

02先看版面

框體提前伸縮，文章及鄰近主題讓出空間。

03放下套用

放下才保存。Esc 取消，↶ 一步復原。

04整理成稿

以關係線寫明觀點，依輸出大綱閱讀或輸出。

右側插入偏向橫排，下側插入偏向直排；選多張時保留彼此的相對位置。Alt 拖曳暫停吸附並移出主題。收合主題停留約 400ms 會預先展開。

把工作區調成順手的樣子

三區都可以收起來

上方按鈕分別控制左側大綱、上方工作區和右側編輯器。「專注畫布」一次收起三區，再按一次恢復。

介面會記住設定，面板變動時保留畫布中心。窄視窗使用單側抽屜。

主題色與可變框型

「主題與介面」提供六組配色、淺色／深色／跟隨系統及自訂重點色。

主題可選圓角、切角、折角便箋、資料夾、對話框或六角框。文章預設繼承主題，亦可單獨修改；右下角控制點調整尺寸。

從閱讀，到自己的判斷

功能怎麼使用
聚焦閱讀卡片「閱讀全文」打開完整圖文，可編輯及對照保留的原文。
雙篇比較Ctrl / Shift 點選兩張文章，按「雙篇比較」，分別寫下觀點與疑問。
主題聚焦主題標題旁的 ◎ 弱化其他材料，保留正在處理的內容；「取消聚焦」恢復全桌。
關係線從卡片頂端 ↗ 拖到另一張卡片，或按「建立關係」。支援支持、質疑、補充、相關及說明文字，點線可追蹤並編輯。
標籤一張材料屬於一個主題，可有多個跨主題標籤；多選標籤顯示符合任一標籤的材料。
書本閱讀長文真正排成多頁，寬視窗雙頁、窄視窗單頁；頁碼與內容錨點保存閱讀位置。停穩後可選字、複製與開啟連結。

書本的「閱讀筆記」自動保存觀點。「編輯這篇」切換平面編輯，完成後重新排頁。動效可關閉，亦尊重系統減少動態效果設定。

圖片、組圖與 PDF

收集圖文

網頁選取文字後按右鍵加入，或由擴充功能工具列匯入文章。段落、標題、清單、連結、圖片來源及圖說保留為結構化內容。

「載入網頁圖片」才要求對應來源權限。下載後保存本機 Blob，離線仍可閱讀。也能加入 PNG、JPEG、WebP 本機圖片。

每張最多 10 MiB、2400 萬像素。登入、防盜連及動態網頁可能限制擷取。

兩種輸出

「輸出圖片」或主題標題旁的 ▧ 產生卡片組圖：摘要、註記、圖片、框型與關係線一併保存，可選 PNG／JPEG、1×／2×。

「文件檢視」依大綱重排全文，再按「列印 / PDF」另存可搜尋 PDF。建議關閉 Chrome 自帶頁首／頁尾。

圖片上限 1600 萬像素、單邊 8192px。過大時降低倍率或減少材料。

資料放在哪裡？

材料、原文、編輯稿、筆記與圖片存於目前 Chrome 設定檔的擴充功能 IndexedDB。日常編輯自動保存，「已儲存」表示寫入成功。

另外保存完整 ZIP。
「備份 / 匯入」可下載目前或全部專案，包含圖文、原文、筆記、圖片、主題、標籤、關係、框型、尺寸及閱讀位置。也能選擇自己的備份資料夾，按鈕備份全部專案。成功寫完才更新備份時間。

程式資料夾和你的資料分別管理。移除插件、清除儲存空間或更換設定檔前先備份。網頁預覽與正式插件也各有自己的資料空間。

安裝與舊資料遷移

  1. 先在既有安裝下載「全部專案 ZIP」；舊版只有 JSON 時，保留原有備份。
  2. 取得 release ZIP 並解壓，或從 repo 建置出 Canvas Clipper/dist。
  3. 在 Chrome 擴充功能頁開啟開發人員模式，以「載入未封裝項目」選擇解壓後包含 manifest.json 的目錄。
  4. 已使用相同固定 ID 的安裝，更新同一目錄後按「重新載入」。新來源 ID 或設定檔則由「備份 / 匯入」匯入 ZIP／JSON。
  5. 核對專案、卡片、原文、筆記及圖片後，再保存新版備份。匯入會建立副本。

更早的 v0.1 可使用原安裝來源下的 migration.html 唯讀匯出全部專案 JSON。原插件 ID 可在 Chrome 擴充功能頁查看，網址形式為 chrome-extension://原插件ID/migration.html。

程式目錄移動可能影響沒有固定 key 的舊版身分；先保留舊安裝完成匯出。新版固定公開 key 已保留。

想看技術細節

「主題與介面」內開啟「技術檢視」，查看繪製模式、DOM 節點、DPI、重繪次數與命中邊界。Repo 的 examples 提供互動 DOM、合成輸出及 WebGL 翻頁三個附註範例。

閱讀桌透過原生 HTML-in-Canvas 繪製可操作 HTML；書本使用實際 HTML 紋理與曲率網格，翻動期間暫停頁面命中，平面後恢復。原文及資料儲存各自獨立。

Chrome 156 需啟用 canvas-draw-element。能力不足時可平面閱讀、編輯及列印；GPU 或原生 API 不可用會顯示狀態。
