# Canvas Clipper v0.4.0：介面與互動更新

本紀錄對應 Canvas Clipper v0.4.0。原始碼、使用指南及建置工具位於 Canvas Clipper 目錄；[Release](https://github.com/show940125/Html-in-Canvas/releases/tag/canvas-clipper-v0.4.0) 提供 ZIP 與 SHA-256。Canvas Slides 維持獨立版本與發布。

## 九項回饋的處理

| 回饋 | 現在的行為 |
|---|---|
| 收合控制應靠近各自面板 | 左側按鈕放在左側標頭，右側按鈕放在右側標頭，上方按鈕放在工作區右上；收起後保留對應邊緣入口。 |
| 上方太佔空間、收合生硬 | 移除大型英文標語與重複說明的顯示，壓縮標題與工具列；一般桌面工作區在提示關閉後從約 181px 開始。面板採 240ms 曲線過渡，過程中保持畫布中心。 |
| 卡片頂端被遮住就無法移動 | 文章文字與空白區都可拖；筆記、連結、按鈕與尺寸控制保留各自操作。雙擊內文仍開全文。主題標題與框內空白也可拖。另提供「定位材料」，將左側選取的材料帶回可見範圍。 |
| 主題上蓋採考題 App 的毛玻璃 | 取用 Law_test 已核准光學樣式的右上清透／左下漸霧、暖白高光與柔和邊緣；Canvas 在場景單元之間實際合成背景模糊與輕微邊緣偏折，前景文章和輸入保持清楚。HTML 模式以相同漸層與 backdrop-filter 呈現。 |
| 字體偏小 | 閱讀字級預設 17px，卡片標題 18px；「主題與介面」可調整 14–22px，重新開啟仍保留。卡片、筆記、編輯器及全文／書本使用相應閱讀字級；PDF 使用文件自己的列印字級。 |
| 重疊層級怪異 | 原先全場景的底框、文章和標題分開繪製，會跨主題交錯。現在每個主題以「底框→所屬文章→自己的上蓋」形成完整單元，操作材料時提升整個單元；HTML 與原生 Canvas 共用排序，關係終點也依前後景判定。 |
| 資料夾框型右上控制貼邊 | 資料夾標頭移至頁籤下方，控制項與框體保留左右安全區及上方間距，標題過長時截短顯示。 |
| 自適應排版瞬間跳動 | 以同一份動畫幾何驅動文章位置、主題伸縮、鄰居讓位、SVG 關係線與原生命中。拖曳中的材料即時跟手，周邊元素平滑讓位；預覽不寫資料，放下提交同一目標。Esc 取消；關閉動效或系統減少動態效果時直接到位，閒置停止更新。 |
| 官方技術與設計技能評估 | 見下列技術優先序與設計說明。 |

這次訊息沒有收到所稱附圖；上述重疊與框型問題由程式與合成場景重現，截圖保存在 output/v04。

## 可再採用的 HTML-in-Canvas 技術

| 技術 | 本插件適合的用途 | 本輪狀態／優先序 |
|---|---|---|
| Multi-Element Composition | 以主題為單位排序、獨立重繪、操作時保持命中一致 | 已落實單元排序與共同幾何；下一步可用 changedElements 減少大型工作區更新成本。 |
| Frosted Glass Backdrop | 主題容器透出下層脈絡，自己的文章保持清楚 | 已落實真實場景背景合成，含方向性霧化與輕微邊緣偏折。 |
| HTML-to-Image | 保存整個主題、圖片與關係線 | 既有功能保留並再測 PNG／JPEG。 |
| Page Curl / Book Turn | 長文分頁與連續閱讀 | 既有 HTML 紋理翻頁保留，原生選字、連結與筆記再測通過。 |
| HTML Video Recording | 錄下整理推理、材料移動與關係建立過程，分享研究脈絡 | 適合下一輪功能；需另設錄影範圍、開始／停止及檔案大小提示。本輪未加入錄影按鈕。 |
| 小地圖／多尺度總覽 | 找回遠處材料、快速跳到主題 | 建議下一個實用功能；本輪先提供定位材料，解除移出畫面後難以恢復的問題。 |
| OffscreenCanvas Worker | 大量材料的圖像合成、低頻縮圖 | 待實際大型工作量量測後採用；需依 ElementImage 能力探測，不能只把 DOM 工作移給 worker。 |
| Liquid Glass／Elastic Bulge／粒子 | 操作邊緣、短暫完成回饋 | 主題背景可用光學邊緣；閱讀文字與輸入保持穩定。持續扭曲或粒子會增加閱讀負擔，不列本輪主要功能。 |

來源：[官方 API 說明](https://developer.chrome.com/blog/html-in-canvas?hl=zh-tw)、[多元素合成](https://html-in-canvas.dev/demos/multi-element-composition/)、[毛玻璃背景](https://html-in-canvas.dev/demos/frosted-glass-backdrop/)、[示範目錄](https://html-in-canvas.dev/demos/)。程式以實際能力判斷分支，保留 HTML 模式。

## baoyu 與歸藏的使用方式

前版主要依 baoyu-design 的產品介面流程實作，沒有完整套用歸藏流程。技能提供方法；介面密度、控制位置與閱讀舒適度仍由實作者判斷與驗證。

本輪以既有 Clipper 與考題 App 程式作為具體參考：baoyu 用於元件狀態、互動與實機畫面檢查；歸藏的內容優先、字級層次、對齊和留白節奏用於收斂閱讀桌。歸藏 Page 的產物是文章精排頁，其渲染器沒有套入這個 React 插件。兩套方法共同服務本輪指定的工具介面。

毛玻璃參考來源是使用者指定的 Law_test 桌面已核准樣式與光學渲染器；本插件重新實作自己的 Canvas 背景合成，沒有加入考題資料或背景照片。

## 驗證與交付界線

- 型別、正式建置及 49 個單元測試通過。
- 本輪 45 項原生／HTML 互動檢查，加上閱讀桌21項、深層流程25項與工作量6項，共 97 項瀏覽器檢查通過；結果見 output/v04/verification.json。
- 實測 Chrome 157.0.8103.39，原生測試帶 CanvasDrawElement 參數；原生檢查含 150% DPI。Chrome156 的能力分支保留，本輪未另啟動156實機。
- 驗證面板與磁吸經過實際中間幾何、預覽不寫資料、停止後無持續重繪、頂端裁切的內文拖曳、完整主題層級、原生中文筆記及窄視窗抽屜。
- 既有全文、雙篇比較、GPU 翻頁、選字與連結、完整字元分頁、JPEG／PNG／PDF、v3 備份與舊版匯入再測。
- 原生圖片來源允許、Windows 資料夾選取、日常設定檔遷移及實體 IME 候選窗仍屬使用者人工操作；本輪沒有重跑需原生授權的測試。
- 先下載全部專案 ZIP，再重新載入目前插件來源。原始資料與父層舊安裝保留。

正式使用請解壓 Release ZIP，以 Chrome「載入未封裝項目」選擇包含 manifest.json 的目錄。從原始碼開發可自行以 HTTP 伺服器預覽 dist；HTTP 預覽與正式插件各自保存資料。
