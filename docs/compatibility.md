# 相容性與驗證邊界

| 環境 | 狀態 |
|---|---|
| Windows、Chrome 156.0.8078.80、CanvasDrawElement 啟用 | 本機隔離設定檔驗證原生繪製、中文輸入、150% DPI、分頁、WebGL 互動及輸出 |
| Chrome 新版 API | 依官方介面提供能力探測及紋理上傳路徑；實機與 CI 結果另外列示 |
| HTML 相容模式／停用原生 API | 保留閱讀桌、圖文編輯、分頁閱讀及列印；圖片組圖需要原生 Canvas |
| WebGL 不可用或中斷 | 切換平面閱讀並顯示原因 |

程式不依版本字串決定 API 分支。Chrome 156 使用者需自行啟用實驗功能；Chrome 官方的新版本資訊見[官方說明](https://developer.chrome.com/blog/html-in-canvas)。

## 輸入與無障礙

卡片與頁面保留真實 HTML。可使用 Tab、文字選取、複製及連結。書本翻動期間暫停頁面命中；減少動態效果設定改為直接換頁。原生中文插入及組字事件可自動驗證；實體輸入法候選字選擇仍建議在自己的環境試用。

## 權限與資料

- 文章擷取使用使用者觸發的 activeTab，沒有常駐的全網站內容腳本。
- 按「載入網頁圖片」才要求對應來源的選用權限；背景程式也會再次檢查權限。
- 資料及圖片保存於目前設定檔內，沒有後端、帳號、追蹤或 API key。
- 圖片限 PNG／JPEG／WebP，每張 10 MiB、2400 萬像素；驗證尺寸後才解碼。SVG 不作為使用者圖片匯入。
- ZIP 總量限制 250 MiB；匯入拒絕異常路徑、缺失圖片及失效引用。

網站登入、防盜連、動態載入、瀏覽器內部頁面及內建 PDF 檢視器有擷取限制。圖片失敗保留替代說明，讓文字整理仍能繼續。

## 測試結果如何閱讀

事件到 paint 的時間代表程式完成下一次 Canvas paint 的延遲，未包含顯示器合成與掃描。有效 paint 幀率也會受瀏覽器排程影響。正式驗收紀錄記錄測試機實際數字，不作為所有設備的保證。

需要使用者互動的來源授權、系統資料夾選取及 Chrome 列印位置，與無互動 CI 分別列示。來源授權測試須使用隔離設定檔及受控本機圖片來源。
