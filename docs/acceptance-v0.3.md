## 工作量與效能

20 張文章、6 張合成點陣圖片、20 條關係線，另測 150% DPI。

| 拖曳量測 | 數值 |
|---|---:|
| 樣本 | 40 |
| 中位數 | 4.3ms |
| p95 | 8.5ms |
| 最大值 | 18.3ms |
| 有效 paint 幀率 | 45.79 fps |

量測範圍為 pointermove 處理到下一次 Canvas paint，未包含顯示器合成與掃描；有效 paint 幀率也受測試排程影響。p95 通過 100ms 目標，這些數字代表本次測試環境。

## 圖片來源授權與人工邊界

同日較早的獨立 headed 測試已通過 5 項：未授權拒絕、來源授權後實際下載、驗證點陣資料寫入、離線重開，以及遠端 SVG 拒絕。

最後整輪 gate 的新設定檔在原生來源授權提示等待逾時；這次重跑尚未取得人工確認，整輪 gate 因此保留失敗狀態。101 項結果與較早的 5 項授權結果分開記錄。Windows 操作工具無法可靠辨識目前瀏覽器網址，停止了自動操作；沒有將這個逾時標示為成功。

使用自己的 Chrome 時，以下仍需人工完成：

1. 更新前從舊安裝匯出全部專案 ZIP，載入新版後確認資料。
2. 按「載入網頁圖片」並確認 Chrome 顯示的來源授權。
3. 選擇備份資料夾、確認作業系統檔案選取器及列印目的地。檔案寫入流程已使用真實 FileSystemHandle／OPFS 驗證；Windows 原生資料夾視窗列為人工步驟。
4. 試用實體中文輸入法候選字。自動化已驗證中文輸入；實體鍵盤與候選窗仍須在使用者設備操作。

Chrome 157 實機尚未取得。新版 API 依能力探測提供相容路徑；CI 結果與本機 Chrome 156 結果分列，未推定為所有 GPU 或 Chrome 版本的保證。
