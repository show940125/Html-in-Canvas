# Canvas Clipper：閱讀工作台 UX 調整

發行版本：**0.5.0**。[下載與發行說明](https://github.com/show940125/Html-in-Canvas/releases/tag/canvas-clipper-v0.5.0)。

主題框右上角的 **⚙ 主題設定** 保留六種框型、主題配色、文章預設框型與文章預設顏色。文章可繼承主題樣式，也能保留自己的覆寫；調整主題外觀不變更摘錄內容與輸出大綱。

本輪最終檢查：型別與建置通過，57項單元測試、58項原生／HTML工作台檢查、22項原生閱讀與GPU檢查、11項無GPU相容檢查、43項真MV3擷取檢查，以及2項審查發現的回歸檢查通過。最後兩項實測包含篩選後搜尋定位與實際產生PDF。CI設定已補入工作台驗收；各次發布以對應提交的 GitHub Actions 結果為準。

本輪依已確認的互動樣板整合 F01–F12。目標是讓收集結果清楚、材料容易找回、閱讀與整理操作各有位置。F13、F14保留為候選，尚未納入本輪正式實作。

本文記錄核准範圍與驗收要求；功能完成及測試結果應以本輪實際驗收紀錄為準。先前 v0.4.0 的測試數量與發布紀錄不代表這次改動已通過驗收。

## 收集與開啟材料的協定

擴充功能內部使用下列訊息；不提供外部網頁呼叫入口。

- `CAPTURE_ARTICLE` 可帶 `projectId`。背景程式在擷取前及寫入前確認目的專案存在。省略時維持目前專案行為。
- 彈窗傳入 `openAfterCapture: false`，保存完成後顯示結果；背景回傳 `projectId`、`projectTitle`、`clipId`。既有訊息預設仍在成功後開啟整理台。
- `OPEN_CAPTURED_CLIP` 帶 `projectId`、`clipId`。背景確認該卡片屬於該專案後，開啟 `index.html?clip=<卡片ID>#project=<專案ID>`。
- `OPEN_WORKSPACE` 維持開啟目前專案的行為。目的專案下拉選擇不改變目前專案偏好；使用者查看材料、進入該專案後才沿用整理台的現有切換規則。

收集失敗時保留來源與目的專案選擇，顯示原因。收集成功後可查看已保存材料，避免再次收集同一篇只為確認結果。

## 資料與驗收界線

正式整合沿用 IndexedDB、v3 ZIP、舊版匯入、原文與整理稿、圖片素材、HTML-in-Canvas 能力偵測及 HTML 相容模式。獨立設計樣板的 JSON 與簡化書本只用於評估介面，不作正式資料格式或分頁實作。

本輪驗收應分別記錄型別、單元、建置、原生 Canvas、HTML 相容模式、實際擴充功能擷取及下載結果。Chrome版本、DPI、減少動態效果和實際走過的操作應記在驗收紀錄，未測項保留明確標示。

2026-11-09 的最終建置已在隔離 MV3 擴充功能擷取驗收通過43項檢查，證據輸出至 `Canvas Clipper/output/v03/extension/extension-acceptance.json`（沿用既有測試輸出目錄名稱）。實際路徑包括三篇本機合成文章、Chrome／MDN／React三個公開網站、每次彈窗成功回饋與查看、第二專案下拉切換、僅寫入選定專案、新卡選取與完整定位、不存在的目的專案拒絕且不寫入、受限頁面錯誤及重載持久化。測試使用包含彈窗專用CSS的最終dist，實際座標點擊與目的地鍵盤切換通過；其他F項由各自驗收紀錄說明。

原生圖片來源允許、Windows資料夾選取／列印目的地、日常設定檔遷移及實體中文輸入法候選窗仍需人工步驟。未操作這些視窗時，不宣稱已完成其端到端驗收。
