# v0.2.0 本機驗證紀錄

日期：2026-11-07。狀態：本機預覽交付，尚未公開發布。依使用者回饋補社群擷取，並將程序骨架角色更換為生成的哥斯拉與自然人物 GIF；新版造型與整體動作品質仍待使用者試看。

## 已完成驗證

- TypeScript 檢查與獨立插件／離線 HTML 建置通過。
- 5 項資料邊界測試：網址協定、損壞快照、文字隔離、演出終止，以及 120 個內容區塊分組後完全保留。
- Chrome 157.0.8103.39 的預覽驗證 26 項通過：原生與強制 snapshot 紋理、角色數量、分鏡、滑鼠引導、暫停、Esc、來源還原、重播、終點、視窗改變、窄螢幕及 GPU 不可用。
- 同版 Chrome 真實 MV3 驗證 21 項通過：工具列動作授予 activeTab，直接操作實際 popup，擷取來源、原生文字／SVG 素材、自然播放、表單草稿與事件保留、終點本機保存及真正網址交接。新增社群頁實際擷取 24 篇貼文與 24 則留言、超過 16 個區塊的覆蓋，以及生成 GIF 圖集路徑。
- 11 項社群擷取回歸通過：X 式 tweetText、一般 div/span 留言、作者、巢狀連結、role 控制、開放 ShadowRoot，並驗證隱藏／畫面外／編輯器排除及清空／還原。
- 9 項素材檢查通過：三份檔案均為真正多幀 GIF，具有不同影格與透明像素；GPU 圖集逐幀與原始 RGBA 像素完全一致。
- 真實 MV3 驗證亦涵蓋使用者指定的 Chrome HTML-in-Canvas 文章與 html-in-canvas.dev 示範集，兩者均使用原生文字紋理並可恢復。
- 1920 × 1080、12 個來源區塊聚成 8 個角色的自然播放量測約 60 fps；記錄 780 個中段影格間隔，實際路徑為 gif-atlas。此結果限本次機器與測試頁，無法代表所有 GPU 或所有網站。
- 原生預覽逐張檢查成形、成形／奔跑交界、逃難及結尾。角色採生成 GIF 的完整姿勢，文字疊入輪廓；加入地裂、碎片、煙塵與人物間距處理。
- 合計 72 項通過：5 單元＋26 預覽＋11 社群擷取＋9 素材＋21 真實插件。

## 實際 X 頁面查核界線

另以連線中的 Chrome 唯讀查看使用者已開啟的 X 貼文留言頁。當時載入 29 個貼文／留言文字區塊，其中 7 個在視窗內；可見文字容器皆為 DIV，內部沒有舊版搜尋的 p。與本次擷取修正的漏點相符。

此項是實際 DOM 查核，並未在使用者登入中的 X 頁面重新載入插件或播放新版動畫；完整擷取與渲染已在重現社群結構的真實 MV3 測試中通過。兩種驗證分開記錄，未改動或送出 X 內容。

## 已知限制與人工試看

- 造型採生成動畫的真實影格；素材原始尺寸約 362–447px，放大細節與循環銜接仍待人工評價。GPU 柔化透明邊緣，未宣稱已達電影級動畫。
- 同層人物有間距處理；目前仍為二維演出，沒有完整三維碰撞或逐字可逆搬運。內容按區域聚成角色。
- 清空背景依賴一次短暫隱藏後的截圖。動態影片、廣告、輪播及擷取期間捲動可能造成畫面差異。
- 「指定網站」以預先捕捉的終點畫面完成視覺變身，再進行一般導向。重新載入、不同視窗比例或即時內容可能造成末尾跳動。
- 原生文字素材是重新排版的演出副本，保留來源文字與必要樣式；原始圖片與複雜視覺使用靜態裁片。
- 尚未載入、畫面外或封閉 ShadowRoot 的文字不在目前擷取範圍；可先捲動至留言區再啟動。沒有音效、錄影、全頁捲動掃描或跨來源框架內部 DOM 拆解。受限頁面無法啟動。
- 動畫由使用者點擊開始；提供隨時暫停和恢復。尚未提供獨立的減少動態演出版本。
