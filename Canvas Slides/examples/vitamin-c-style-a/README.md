# 維他命 C 的好處 · 風格 A · 五頁

本檔是正常的 HTML 簡報，也用來測試 Canvas Slides 的匯入與在線編輯。採雜誌風／森林墨主題，繁體中文，五頁各用一種版型。所有文字、卡片、圖片與流程均為獨立 HTML 元素。

## 開啟與匯入

- 直接播放：開啟 `維他命C的好處_風格A_五頁.html`。圖片、圖示與播放 runtime 已嵌入，可離線開啟。
- 測試素材匯入：在 Canvas Slides 按「匯入」，選 `維他命C_風格A_在線編輯測試.zip`。ZIP 內的 `index.html` 使用相對圖片路徑，可測試素材解析與納入。
- 也可直接匯入單一 HTML；這條路徑使用已嵌入的圖片。
- 左右方向鍵翻頁；最後一頁的流程可逐步推進。P 開啟講者模式，Esc 開啟／關閉頁面總覽。

## 五種版型與建議測試

| 頁 | 版型 | 建議操作 | 預期結果 |
|---|---|---|---|
| 1 維他命 C | M01 大字封面 | 雙擊主標題改字，調整字級與顏色，再復原 | 文字保持可編輯，其他元素維持原位 |
| 2 修復的底氣 | M04 左文右圖＋引言 | 換成另一張附圖，切換裁切焦點；把引言轉成自由物件 | 圖片能替換，文案獨立保存；拆開區塊不推動鄰近內容 |
| 3 四個好處 | M03 四格資訊卡 | 從圖層選取整張 stat-card，拆開、拖拉、縮放；多選兩張卡對齊 | 以卡片為單位操作，標題與說明保留 HTML |
| 4 補足就好 | M09 雙欄比較 | 修改清單、拖動兩欄、群組、旋轉、解散，再復原 | 排版與階層保存，群組操作維持視覺位置 |
| 5 把 C 吃進去 | M06 四步流程＋圖片 | 改步驟標題、換圖；把此頁移到第二頁並修改備註 | 頁面與備註依穩定 ID 對應；重新播放保留修改 |

完成後匯出「可再編輯專案」ZIP，重新匯入副本，檢查文字、圖片、幾何、順序與講者備註。再輸出 HTML，於未安裝插件的分頁播放。

若要移動整組內容，先從圖層選取容器；單擊文字通常只選到文字元素。圖片不是整張投影片截圖，文字不會因換圖而改變。

## 內容與素材

內容採一般營養科普角度。來源列於每頁頁腳與 `SOURCES.md`；補充劑的研究界線也保留在簡報中。兩張蔬果與餐盤攝影為 AI 生成示意，未用來代表實測營養含量。

此檔提供五種代表版型，並未把十種風格 A 版型擠在同一份五頁簡報裡。全份使用相同配色與字體階層。

設計來源與播放模板：既有 guizang-html-ppt skill；未修改來源 skill。實際匯入測試發現風格 A 被誤判為瑞士風，Canvas Slides v0.1.1 已修正；請使用 v0.1.2（含底色、列印及逐步播放修正）測試此簡報。

## 從原始碼重建

在 `Canvas Slides` 執行 `npm ci`、`npm run build`、`node examples/vitamin-c-style-a/build.mjs`，即可產生上述 HTML 與匯入 ZIP。生成檔以發布附件交付；來源、圖片及講者備註保留於 repo。
