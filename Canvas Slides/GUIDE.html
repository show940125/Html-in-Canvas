Canvas Slides

v0.1.2 本機預覽版

保留 HTML 的排版與文字，讓 AI 生成的簡報可以在 Chrome 裡繼續編輯。

載入插件

  1. 將測試 ZIP 解壓到固定資料夾。
  2. 在 Chrome 開啟 chrome://extensions，啟用右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選擇含 manifest.json 的資料夾。
  4. 按 Canvas Slides 插件圖示進入編輯器。

開始做一份簡報

直接編輯起始頁，或按左上角品牌建立歸藏瑞士風／雜誌風簡報。按「匯入」選擇 HTML、素材或 ZIP；資料夾匯入位於工作室。

單擊選取物件、雙擊文字編輯，Shift 多選。需要重新組版時，按右側「轉成自由物件」。新增圖片後可換圖、裁切、拖拉、縮放與旋轉。

保存與交付

確認頁首顯示「已存到此瀏覽器」。匯出「可再編輯專案」保存原稿與素材；匯出「獨立 HTML」可直接播放。PNG 使用原生 Canvas，PDF 從列印視窗另存。

播放分頁提供講者備註、下一頁預覽與手動計時。輸出的歸藏 HTML 也保留原版講者模式。

目前的驗收邊界

Chrome 156 原生模式需啟用 chrome://flags/#canvas-draw-element 並重新啟動瀏覽器。未啟用時保留 HTML 相容編輯。

實體中文輸入法候選窗、Chrome 157、系統資料夾選取與列印位置仍待實機驗收。任意 HTML 的腳本生成圖表與遠端地圖目前採受限匯入。
